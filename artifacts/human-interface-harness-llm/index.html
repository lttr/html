Human → Interface → Harness → LLM

The layers between you and the model when using a coding agent. Hover a layer for details.

Human

States the goal, reviews results, steers.

Interface

Where you type and read: chat UI, diff views, terminal.

T3 Code, Codex App, TUIs, GUIs

Harness

Runs the agent loop: builds the prompt and context, calls tools, applies edits, handles permissions.

Claude Agent SDK, Codex CLI, Pi

LLM

Takes text (and tool results) in, gives text and tool calls out. Holds no state between calls.
