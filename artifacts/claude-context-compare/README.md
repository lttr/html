## The config being measured

"Lukas' config" is the [settings.json](https://github.com/lttr/dotfiles/blob/master/claude/settings.json) from my dotfiles. It trims features I rarely use to keep the startup context small. The [config README](https://github.com/lttr/dotfiles/blob/master/claude/README.md) explains each choice and how to turn it back on.

What it changes:

- **Context savers**: turns off auto-compact (frees the autocompact buffer), auto memory, workflows, claude.ai connectors and claude.ai skill/plugin sync. Skill listing is trimmed per skill with `skillOverrides`.
- **Denied tools**: a tool in `permissions.deny` is removed from the tool list, not just blocked. Denied: `AskUserQuestion` (replaced by a "**?**" question convention in `CLAUDE.md`), plan mode, cron/`ScheduleWakeup` (`/loop`), `ReportFindings`, `NotebookEdit` and `PushNotification`.
- **Other opt-outs**: UI extras like prompt suggestions, away summary, spinner tips and remote control.

Use `--settings '{...}'` to try a single setting for one session. `claude -p "/context"` measures the result. Print mode doesn't load interactive-only tools like `AskUserQuestion` or plan mode, so interactive `/context` shows higher numbers.
