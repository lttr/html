# Intent: html.lukastrumm.com, a site for HTML artifacts and tools

A simple site for HTML artifacts and small tools, similar to Claude Artifacts and Simon Willison's tools.simonwillison.net. Whenever a small HTML app is built, by hand or with an AI agent, it can simply be published here.

- Domain: `html.lukastrumm.com`
- Each artifact lives in its own folder, e.g. `/artifacts/<slug>/index.html`, plus optional CSS/JS files and an optional `README.md` as an info page.
- Standard attributes per artifact: name, slug, publish date, short description, readme.
- Hosting: Netlify via the `ntl` CLI (logged in; Lukas creates the subdomain).
- Source: public GitHub repo, pushed with `gh` when the repo is ready.
- First artifact: `/tmp/claude-context-compare.html`, generated by `~/dotfiles/scripts/ai/claude-context-compare.ts`.
