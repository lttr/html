# html.lukastrumm.com

Self-contained HTML artifacts and tools.

Add `artifacts/<slug>/index.html`, an optional `README.md`, and a line in `artifacts/index.html` (with a readme link if there is one). Netlify serves `artifacts/` as is, no build step.

Inspired by:

- [Simon Willison's tools](https://tools.simonwillison.net/)
- [The unreasonable effectiveness of HTML](https://thariqs.github.io/html-effectiveness/)
- [Claude Artifacts](https://claude.com/features/artifacts)
